# OOPG

Um jogo de RPG em linha de comando feito em Python, com foco em programação orientada a objetos.

## Sobre o projeto

OOPG é um pequeno RPG de terminal em que o jogador explora biomas, encontra inimigos, luta, usa itens e evolui de nível. O projeto foi criado como um exemplo simples de uso de classes, objetos e lógica de jogo em Python.

## Funcionalidades

- Exploração aleatória em diferentes biomas
- Encontros com inimigos
- Sistema de batalha com ataque e defesa
- Uso de poções para recuperar vida
- Inventário e status do jogador
- Progressão de nível e experiência
- Estrutura em classes com Player e Enemy

## Como jogar

1. Certifique-se de ter Python 3 instalado.
2. Abra o terminal na pasta do projeto.
3. Execute:

```bash
python main.py
```

## Estrutura do projeto

- `main.py` - fluxo principal do jogo
- `player.py` - classe do jogador e suas ações
- `enemy.py` - classe dos inimigos
- `utils.py` - utilitários auxiliares

## Requisitos

- Python 3.8+

## Observações

Este é um projeto simples, pensado para aprendizagem e experimentação com OOP em Python. A lógica do jogo é direta e foi construída para ser fácil de entender e modificar.
